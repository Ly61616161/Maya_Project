# MuscleMan 绑定说明

## 基本信息
- 角色：肌肉男
- 绑定文件：MuscleMan_Rig_v03.ma
- 绑定方式：自研 Python 插件生成基础骨架 + 手动修型
- 蒙皮骨骼：约 90 根
- 控制器：约 100–120 个（含隐藏辅助控制器）
- 蒙皮：Smooth Bind

## 实现功能

### 躯干
- 脊椎 IK/FK 共存
- Twist 骨骼旋转
- 躯干拉伸

### 脖子
- 同躯干（IK/FK 共存、Twist、拉伸）

### 四肢
- IK/FK 切换
- 四肢拉伸
- 弯曲变形
- Twist 骨骼旋转

### 肩膀
- 特殊绑定：肩膀骨骼支持独立移动和旋转
  - 方式：约束
  - 用途：正确的肩膀运动姿态
- 肌肉联动：肩膀骨骼驱动肩胛骨、胸肌、斜方肌、背阔肌
  - 方式：骨骼约束
  - 特点：肩膀运动时，背部肌肉自动跟随
  - 效果：模拟人体解剖，展现肩部的肌肉联动效果

### 手臂
- 大臂空间切换（世界/局部/父级）
- 手臂 IK 控制器空间切换（世界/局部/父级）

### 脚部
- 通用脚部绑定，属性控制：
  - 左右翻脚
  - 踮脚尖
  - 后脚跟

### 肌肉修型
- 全身关节肌肉修型：大臂、手肘、大腿、膝盖、手腕、脚腕等

## 已知限制
- 面部绑定未做，原因：模型面部布线有问题，重复碎点太多，不适合做表情绑定
